# Decisions log

Short record of choices made along the way. Bigger, interview-worthy choices get an ADR in `docs/adr/`.

| Date       | Decision                                                                                                                                                                                                                                           | Why                                                                                                                                                                                                      |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-30 | Project name is **Porter** (not "Portage").                                                                                                                                                                                                        | Owner's choice.                                                                                                                                                                                          |
| 2026-10-30 | GitHub `abhijoshi23`. npm packages are `@abhijoshi23/porter-*`, and registry names are `io.github.abhijoshi23/porter-*`.                                                                                                                           | GitHub auth on the MCP Registry requires the `io.github.<user>/` prefix.                                                                                                                                 |
| 2026-10-30 | **Zero cost** is a hard constraint.                                                                                                                                                                                                                | Owner's requirement. See "Cost plan" below.                                                                                                                                                              |
| 2026-10-30 | Proposals P1–P10 from `mcp-notes.md` are adopted by default.                                                                                                                                                                                       | No objection raised. Revisit if the owner disagrees.                                                                                                                                                     |
| 2026-10-30 | TypeScript pinned to 6.0.x (not 7).                                                                                                                                                                                                                | typescript-eslint 8.x supports TS `<6.1`. Revisit when it supports TS 7.                                                                                                                                 |
| 2026-10-30 | Exact dependency versions (`save-exact`).                                                                                                                                                                                                          | Supply-chain hygiene. Dependabot proposes the bumps.                                                                                                                                                     |
| 2026-10-30 | Tool result text = summary + JSON in one text block, alongside `structuredContent`.                                                                                                                                                                | Many clients only pass `content` to the model, and the spec says tools with an output schema SHOULD include serialized JSON.                                                                             |
| 2026-10-30 | Dropped `undici`; the HTTP client uses global `fetch` with an injectable `fetch`.                                                                                                                                                                  | Fixture record/replay injects `fetch` directly, which avoids mismatches between npm undici and Node's bundled undici.                                                                                    |
| 2026-10-30 | Modern-era tests drive `createMcpHandler(...).fetch` through the client's HTTP transport, with `legacy: 'reject'`.                                                                                                                                 | `InMemoryTransport` only speaks 2025. Rejecting legacy makes any silent fallback fail loudly.                                                                                                            |
| 2026-10-30 | HTTP mode refuses to start on a non-loopback bind without `PORTER_ALLOWED_HOSTS`.                                                                                                                                                                  | Failing closed against DNS rebinding.                                                                                                                                                                    |
| 2026-10-30 | `porter-hello` is `private` (never published).                                                                                                                                                                                                     | It is a reference only.                                                                                                                                                                                  |
| 2026-10-31 | Persistent download cache is file-based (URL-hash files + `.meta.json`), not `node:sqlite`.                                                                                                                                                        | Works on the owner's Node 22.12 and needs no native dependency. SQLite is still planned for the GTFS/tenders indexes.                                                                                    |
| 2026-10-31 | Added a third StatCan tool, `statcan_get_table`, beyond the brief's two.                                                                                                                                                                           | The model needs exact dimension/member names before `statcan_get_series`. Folding them into find_table would bloat every search result.                                                                  |
| 2026-10-31 | `query_resource` and `preview_resource` support CSV only. ZIP (StatCan bulk) and XLSX are refused with a hint.                                                                                                                                     | DuckDB's Excel reader is an extension, and extensions are disabled in the sandbox. StatCan data is better served by the WDS tools.                                                                       |
| 2026-10-31 | A fresh DuckDB instance per SQL call.                                                                                                                                                                                                              | Isolation over speed. Loading a cached CSV takes well under a second at typical sizes. Revisit with an LRU of locked instances if evals show latency problems.                                           |
| 2026-10-31 | The StatCan table-list fixture is trimmed (8,280 → 303 tables).                                                                                                                                                                                    | Keeps the repo small (fixtures 6.0 MB → 596 KB) while keeping realistic search noise.                                                                                                                    |
| 2026-10-31 | Geography members are labelled from the table's hierarchy, and duplicates are selectable as `id:<n>`.                                                                                                                                              | Real census tables contain several members named exactly "Waterloo". Labels alone ("Waterloo") would leave the model unable to choose.                                                                   |
| 2026-10-31 | One portal failing doesn't fail `search_datasets`; the failure is reported in the summary.                                                                                                                                                         | Partial results are more useful than an error.                                                                                                                                                           |
| 2026-11-02 | GTFS schedules are stored in **DuckDB** (one file per feed version), not `node:sqlite`.                                                                                                                                                            | Already a dependency and proven on CI. Columnar storage sorted by stop answers "next departures" in ~3 ms over TTC's 3.3 M stop times, and works on Node 22.12.                                          |
| 2026-11-02 | Built-in ZIP reader and GTFS-RT protobuf decoder instead of `yauzl` and `gtfs-realtime-bindings`/`protobufjs`.                                                                                                                                     | Each is ~200 lines over `node:zlib` or the wire format, avoids ~1 MB of dependencies, and lets us enforce zip-bomb and bounds checks ourselves.                                                          |
| 2026-11-02 | GO Transit realtime is not included.                                                                                                                                                                                                               | It needs a Metrolinx API key, and code that can't be tested without one would ship unverified. Tools say "scheduled only" for GO.                                                                        |
| 2026-11-02 | Realtime older than 5 minutes is ignored and reported as stale.                                                                                                                                                                                    | On 2026-11-02, GRT's trip-updates endpoint served a snapshot from 2026-02-17. Applying it would invent delays.                                                                                           |
| 2026-11-02 | Realtime is matched by `stop_sequence` first, then `stop_id`.                                                                                                                                                                                      | TTC's realtime stop IDs often differ from its static ones (18.5 k of 31.6 k matched), while sequences are unique within a trip.                                                                          |
| 2026-11-02 | First use of a large feed returns a retryable "still preparing" error after 25 s while the build continues.                                                                                                                                        | A 70 MB TTC download can outlast a client's tool timeout, and a timeout tells the model nothing.                                                                                                         |
| 2026-11-02 | Same-name stops within 400 m are one place (word order ignored); different places are never merged.                                                                                                                                                | Riders mean every bay of "Ainslie Terminal" and every corner of "KING at JAMES" / "JAMES at KING" (HSR). Two "Elm St" stops 5 km apart stay ambiguous.                                                   |
| 2026-11-02 | A bare number is read as the stop-sign code before the stop_id.                                                                                                                                                                                    | That's what riders know, and HSR's code and id ranges overlap. Our own labels always use the unambiguous `id:<n>` form.                                                                                  |
| 2026-11-02 | `plan_simple_trip` plans direct rides only.                                                                                                                                                                                                        | Transfers need a real router (RAPTOR). The tool says when a transfer is needed instead of inventing one.                                                                                                 |
| 2026-11-02 | Evals score with deterministic checks (tool calls, args, order, answer regexes), not an LLM judge.                                                                                                                                                 | Reproducible, unit-testable and free. A judge would add cost and its own variance.                                                                                                                       |
| 2026-11-02 | Evals run against live data; checks assert behaviour, and exact values only where stable (census counts).                                                                                                                                          | Replaying fixtures would break as soon as a model made a call nobody recorded. Live data is what users get.                                                                                              |
| 2026-11-02 | The Claude Code driver isolates runs: `--tools ""`, `--strict-mcp-config`, `--setting-sources ""`, empty cwd. Not `--bare`.                                                                                                                        | Scores must reflect Porter's tools only (no web-search fallback, no project context). `--bare` requires a paid API key instead of the login.                                                             |
| 2026-11-02 | The Ollama driver accepts tool calls written as JSON text when the whole reply is a call to a real tool.                                                                                                                                           | qwen2.5-coder (7b and 14b) emits calls that way. Without the fallback it would score zero on formatting, which says nothing about tool design.                                                           |
| 2026-11-02 | `statcan_get_series` reads census tables by coordinate, and its default window ends at the table's latest data.                                                                                                                                    | Found while writing evals: census tables have no vectors (vectorId 0), and "5 years before today" excluded the 2021 Census. Both made census values unreachable.                                         |
| 2026-11-02 | Attempts that fail for infrastructure reasons (timeouts, API errors, the machine sleeping) are excluded from pass rates and counted separately.                                                                                                    | The first after-fix run was spoiled by the laptop sleeping. Those failures say nothing about the tools. Runs now use `caffeinate`.                                                                       |
| 2026-11-02 | Eval checks assert outcomes where the server resolves for the model (e.g. the departures came from Union Station GO), not the model's literal arguments.                                                                                           | Once the server resolved "Union Station" correctly itself, an argument check punished the better design.                                                                                                 |
| 2026-11-02 | Stop resolution prefers the single station/rail match among equals, and says what else matched.                                                                                                                                                    | Evals: "Finch Station" matched 36 TTC stops; GO "Union Station" matched the train station and bus terminal. Choice is visible and reversible via `id:`.                                                  |
| 2026-11-02 | Eval results (traces and reports) are committed.                                                                                                                                                                                                   | ~0.5 MB. Lets reviewers check the numbers in the README against raw traces. Contains only public data.                                                                                                   |
| 2026-11-03 | CanadaBuys closing times are read as Eastern wall-clock time (America/Toronto, DST applied), not the fixed UTC−05:00 the data dictionary states.                                                                                                   | The data contradicts the dictionary: closings cluster at 14:00 in summer and winter alike, and those notices' descriptions say "14:00 EDT". Reading UTC−5 would make every summer deadline an hour late. |
| 2026-11-03 | Tender status comes from the closing time, not the file's "Open" label.                                                                                                                                                                            | The open-notices file still lists notices that closed months earlier (some in 2025). Telling a bidder a closed tender is open is the costliest mistake this server could make.                           |
| 2026-11-03 | Tenders: in-memory BM25 plus a topic → UNSPSC map, no database.                                                                                                                                                                                    | ~900 open and ~4–8 k closed notices index in well under a second. No native dependency, so the server can ship as a single cross-platform `.mcpb`. Replaces the SQLite FTS5 plan (P8).                   |
| 2026-11-03 | Closed notices come from the fiscal-year files, loaded only when needed.                                                                                                                                                                           | 25–40 MB each. Most questions are about open notices; "is X still open?" needs history, so it's fetched on first use and cached.                                                                         |
| 2026-11-03 | `summarize_tender_fit` uses rules with quoted evidence, not a model. Silence is `not_stated`; "may be set aside" is `possible`.                                                                                                                    | Deterministic, free and checkable. Most set-aside mentions are boilerplate. Calling silence "none" would hide a security requirement that's only in the documents.                                       |
| 2026-11-03 | CI: actions moved to their Node 24 majors; Dependabot skips TypeScript 7 and `@types/node` majors.                                                                                                                                                 | GitHub is retiring Node 20 actions. TypeScript 7 breaks typescript-eslint (Dependabot PR #1 failed lint), and the Node types must match the oldest supported runtime, Node 22.                           |
| 2026-11-03 | porter-tenders sends `porter-tenders/<version>` as its User-Agent, without the `(+https://…)` contact link the other servers send.                                                                                                                 | canadabuys.canada.ca answers 403 to the longer form and 200 to this one. It still identifies the tool honestly, and it is free (the alternative was waiting on PSPC).                                    |
| 2026-11-04 | Writes need the user's approval: elicitation when the client supports it (`input_required` in 2026, `elicitation/create` in 2025), otherwise a preview plus an HMAC token bound to the resolved request. [ADR-004](adr/004-write-confirmation.md). | A `confirm`/`dryRun` flag is written by the model and proves nothing. Tokens are stateless, so they work with the 2026 stateless protocol and across replicas.                                           |
| 2026-11-04 | QuickBooks tokens are stored AES-256-GCM encrypted with a key derived (HKDF) from the client secret. No keychain dependency.                                                                                                                       | No extra secret to manage, and the file is useless without the secret, which lives in the client config. Keychain access would need a native module per platform.                                        |
| 2026-11-04 | QuickBooks auth is a separate CLI step (`porter-quickbooks auth`), not a tool.                                                                                                                                                                     | The browser consent needs a person. Doing it inside a tool call would leave the server waiting on a browser the model can't see. Remote OAuth comes with Milestone 7.                                    |
| 2026-11-04 | Six task-shaped QuickBooks tools instead of endpoint wrappers. AR aging is computed from open invoices, not Intuit's aging report; P&L uses Intuit's report.                                                                                       | Aging from invoices gives per-invoice detail (which invoice to chase) and works the same in every company. The P&L must match what the accountant sees, so it comes from QuickBooks.                     |
| 2026-11-04 | `QUICKBOOKS_ENVIRONMENT=demo`: a sample company served in memory by the same fake the tests use, dates moved to the current month.                                                                                                                 | Free to try with no Intuit account, gives evals fixed figures to check, and can back the hosted demo (Milestone 7) without real books or credentials.                                                    |
| 2026-11-04 | QuickBooks API minor version pinned to 75.                                                                                                                                                                                                         | Intuit retired 1–74 on 2025-08-01 and answers anything lower as 75. Pinning keeps the response shape from moving under us.                                                                               |
